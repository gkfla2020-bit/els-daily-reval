# ELS 일일 재평가 시트

코스피200·HSCEI 스텝다운 ELS 5종을 **매일 장 마감 뒤 다시 평가**하고, 전일 대비 변동을 **기초자산·변동성·금리·시간 효과**로 나눠 엑셀 파일 하나로 남깁니다.
GitHub Actions가 평일 18:40(KST)에 실행하고, 결과는 웹 화면과 날짜별 엑셀로 쌓입니다.

- 결과 화면: https://gkfla2020-bit.github.io/els-daily-reval/
- 최신 엑셀: https://gkfla2020-bit.github.io/els-daily-reval/latest.xlsx
- 매일 실행 기록: [Actions](../../actions) · 날짜별 기록: `state/history.json`, `docs/runs/<날짜>/`

## 엑셀 시트

| 시트 | 내용 |
|---|---|
| 결과 | 종목별 오늘 값, 전일 값, 변동, 기초자산·변동성·금리·시간 효과, 설명 안 된 부분, MC 표준오차, 점검 표시(낙인 근접·낙인 발생 등) |
| 입력 | 코스피200·VKOSPI 종가, HSCEI 종가·실현변동성, 국고채 3년. 출처·주소·받은 시각·기준일 |
| 상품 | 발행일, 최초 기준가(발행일 실제 종가), 조건, 평가일, 현재 수준, 발행 후 최저, 낙인 여부, 다음 평가일 |
| 그릭스 | delta(1%당)·gamma·cross gamma·vega(1%p당)·rho(1bp당)·theta(1영업일), 전일 그릭스로 예측한 변동 vs 실제 변동 |

| 점검 | 9개 점검 통과/실패 |
| 실행 로그 | 날짜별 실행 시각·위치·점검·상품 값 |
| 가정 | 모형과 단순화 가정 |

## 변동 분해와 같은 난수

어제 입력에서 시작해 기초자산(낙인 상태 포함) → 변동성 → 금리 → 시간 순서로 입력을 하나씩 오늘 값으로 바꿔 가며 다시 평가합니다.
모든 재평가에 같은 난수를 쓰고, 난수 열을 '발행 후 몇 번째 영업일'에 맞춰 정렬합니다(`els_daily/model.py`). 그래서 어제와 오늘의 차이에는 MC 잡음이 거의 남지 않고, 입력 변화의 효과만 남습니다.
'설명 안 된 부분' = (오늘 값 − 전일 기록 값) − 네 효과의 합입니다. 같은 코드·같은 난수라면 0이어야 하므로 0이 아니면 입력 수정·코드 변경을 의심합니다.

## 점검 9개

1. 입력 수집 2. 기준일 3. 값 범위 4. 하루 변동 한도(이상치) 5. 두 출처 교차 확인(KRX vs Yahoo 코스피200)
6. 경로 생성기 = QuantLib 해석해(두 지수 ATM 콜) 7. 경로 상관계수 8. 가격 범위·MC 표준오차 9. 변동 분해 합·재현성

6·7번과 8번의 가격 범위는 [ELS 헤지 프로젝트](https://github.com/gkfla2020-bit/quantlib-st-portfolio) 7절 점검을 매일 시장값으로 다시 돌리는 것이고, 나머지는 일일 운영용으로 새로 넣었습니다.

## 가정과 한계

- 엔진: `els_daily/els.py`는 quantlib-st-portfolio의 `notebooks/els.py`(커밋 ae8b412)를 그대로 복사했습니다. 위험중립 상관 GBM, 하루 1단계, 경로 10,000개.
- **[가정]** 코스피200 변동성은 VKOSPI(30일 내재변동성)를 만기 전체에 그대로 씁니다. HSCEI는 내재변동성 무료 시계열이 없어 60영업일 실현변동성으로 대신합니다.
- **[근사]** 금리는 국고채 3년을 연속 복리로 바꿔 모든 만기에 씁니다.
- **[예시]** 상품 조건·배당·상관·퀀토 값. 최초 기준가만 발행일 실제 종가입니다. 실제 상품 가격이나 투자 권유가 아닙니다.
- 원자료 시계열은 저장소에 넣지 않고, 평가에 쓴 값과 출처·받은 시각만 남깁니다.

## 실행

```
python3.13 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q tests/
.venv/bin/python run_daily.py              # 장 마감(15:45 KST) 뒤
```

상품을 바꾸려면 `tools/setup_products.py`의 `SPECS`를 고치고 `python tools/setup_products.py <평가 시작 전날>`을 한 번 돌립니다.
